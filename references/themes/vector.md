## 视觉识别

**灰白底、紫色矢量与酸黄色斜角**。紫色与酸黄组合，像素化箭头、方格与切角形成明显方向性；灰底承载正文，黑色用于强对比。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 底色 | `#E8E8E3` |
| 正文 | `#252729` |
| 次字 | `#676A67` |
| 紫色 | `#8E4CF4` |
| 酸黄 | `#DFE329` |
| 白色 | `#FAFAF5` |
| 深紫 | `#573287` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：微软雅黑粗体标题，Bahnschrift 英文和数字，Consolas 小字号资料编号。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 浅灰左文、右侧紫色折面主视觉，酸黄只放边角；标题不要切碎成难读的字。 |
| 目录 / 章节 | 目录使用斜向推进关系和大编号，章节用单一方向的紫色构件。 |
| 正文 / 图文 | 正文以灰白水平网格承载，斜角在页面边缘，文字保持水平。 |
| 对比 / 表格 | 方案对比使用相同字段，紫/深灰区分；表格黑字浅底，黄线少量突出关键行。 |
| 流程 / 数据图 | 流程箭头用原生对象；装饰像素箭头与信息箭头分区。图表只用资料真实数据，紫色为主。 |
| 结尾 | 结尾收束为一组矢量折面与短标题。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：初代灰白、紫色折面与像素方向图形，稀疏酸黄角标；资料物件在右侧模块化台座中呈现，保持可读留白。
- 透明装饰：紫色方向鳍片、白色像素边和酸黄折角形成单个透明构件。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。
