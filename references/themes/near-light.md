## 视觉识别

**现代骑士竞赛、霓虹都市与晨光**。现代商业都市中的骑士竞技，银白装甲、金色晨光与冷暖霓虹产生张力；刀锋般的斜向光与城市竖线形成动势。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 深底 | `#171D2A` |
| 正文 | `#F3EDD9` |
| 次字 | `#BDC7C9` |
| 晨金 | `#D7B769` |
| 浅纸 | `#EFECDD` |
| 冷青 | `#55BFC9` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：微软雅黑中文，Bahnschrift 粗体英文/编号；少量宋体可用于章节短标题，但正文统一。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 夜色短标题与右侧金色晨光，主体是现代建筑或资料物件，保持夜尽将明的明暗关系。 |
| 目录 / 章节 | 目录用竞赛记录般的清晰条目，章节可从深夜切到象牙白。 |
| 正文 / 图文 | 正文采用象牙白/浅灰阅读版，暗底页面只放短段，霓虹集中在图片外缘。 |
| 对比 / 表格 | 对比与表格保持统一列宽，深墨表头、淡金横线，金色只标重点。 |
| 流程 / 数据图 | 流程用原生线和节点，斜向光不穿过标签；图表用深墨与晨金区分，完整标注单位。 |
| 结尾 | 结尾可用更亮的晨光版本，保留一个金属构件，减少霓虹。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：现代竞技都市的夜色与金色晨光，少量冷青/暗红灯光；资料物件作为城市或科研概念的视觉主体，不生成中世纪城堡。
- 透明装饰：单件银白金属底座与细长金色光鳍，少量冷青反射，真实透明底；避免复制官方骑士徽记。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。

不是通用金色中世纪幻想，也不同于阵地足球的高饱和蓝紫赛事包装。
