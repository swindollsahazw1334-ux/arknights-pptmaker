## 视觉识别

**黑白城市、剧院叙事与少量暗红**。黑白城市与灰色人物主视觉，叙事中出现剧院、秩序和雨季；暗红与旧金只是克制的强调，避免把“意式”直接翻译成满页金色花纹。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 深底 | `#202526` |
| 银灰 | `#B9BCB8` |
| 浅纸 | `#E1DDCF` |
| 正文 | `#EDEAE0` |
| 次字 | `#B5BAB5` |
| 暗红 | `#A83F36` |
| 旧金 | `#9E8C62` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：中文标题可用宋体或较有分量的微软雅黑；正文微软雅黑，英文标题少量 Georgia，数字用 Consolas。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 深灰大标题区与右侧雨夜建筑/资料概念图，暗红只作一处强调。 |
| 目录 / 章节 | 目录像剧目单，章节用短标题、单个序号和建筑裁片；不强行添加剧情台词。 |
| 正文 / 图文 | 正文转为浅纸和深墨，图片像档案照片；保留现代信息网格。 |
| 对比 / 表格 | 对比用对齐的案卷字段，表格银灰分隔、深色标题，真实证据保持原色。 |
| 流程 / 数据图 | 流程像案件关系图，关系和标签均原生；图表可用暗红/墨色区分，不加虚构血债或家族数值。 |
| 结尾 | 结尾以安静建筑轮廓、短标题与少量旧金细节收束。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：雨夜灰阶城市、剧院建筑切片与浅纸/深灰对照；资料概念融入现代城市，不照搬人物和活动标志。
- 透明装饰：单件灰银柱廊碎片或幕帘纸饰，旧金细边与一小段暗红丝带，真实透明底。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。

不等于金黑奢侈品模板；不把灰度处理施加在资料证据图上，也不套用不义之财的酸黄警戒带。
