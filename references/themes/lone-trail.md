## 视觉识别

**暖纸档案、橙带与多色色签**。暖纸档案界面、橙色脊线、黑色字段栏、薄荷绿/赭黄/红色色签；轨道细线、超大浅色编号与规则网格支撑科研档案气质。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 纸底 | `#F2EDD8` |
| 浅面 | `#E9E3C8` |
| 正文 | `#242825` |
| 次字 | `#777665` |
| 橙色 | `#E8753C` |
| 薄荷 | `#8EB8A6` |
| 赭黄 | `#D6AE48` |
| 警示 | `#A54D3D` |
| 细线 | `#CFC8AD` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：微软雅黑中文，Bahnschrift 英文标题，Consolas 档案编号、刻度与短标签。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 左侧橙带与大标题，右侧资料概念/轨道构件，浅色大编号形成层次。 |
| 目录 / 章节 | 目录用纵向档案条目、黑字段与色签；章节仅留一个大编号和短标题。 |
| 正文 / 图文 | 正文暖纸深墨，照片窗和图注独立；薄荷、赭黄可按章节变化，警示红需有内容理由。 |
| 对比 / 表格 | 对比用两个对齐档案栏，表格深色表头、浅纸格与轻分隔线。 |
| 流程 / 数据图 | 流程节点和细连线原生，橙色强调当前阶段；图表完整标注单位，少量色条与数值即可。 |
| 结尾 | 结尾用短句、编号与少量轨道构件，按指定总页数收束。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：暖纸档案面、橙色脊线、少量黑字段造型和浅编号位置；资料主题变成科研观察或独立物件，所有可读编号另排。
- 透明装饰：轨道纸饰、穿孔尺、档案边签或薄荷/赭黄构件，分别透明生成；细小正文不要用低对比橙或薄荷色。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。

不是通用深蓝航天 HUD。轨道细线是装饰，不能替代有语义的原生连线和真实数据图。
