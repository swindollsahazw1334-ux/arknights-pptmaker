## 视觉识别

**蓝紫色赛事包装与绿色场地**。高饱和蓝紫、白色大字与绿色场地形成对比；斜向速度条、细网格、奖杯与台座强调赛事感。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 主蓝 | `#2235F2` |
| 紫色 | `#783FEF` |
| 白字 | `#FFFFFF` |
| 深底 | `#16184A` |
| 正文 | `#20243C` |
| 场地绿 | `#82C654` |
| 金色 | `#D0A446` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：微软雅黑中文标题与正文，Bahnschrift 粗体英文与数字；英文斜体只用于短标签。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 蓝色主场配白色大标题，右侧用资料相关的立体主物件；金色只点缀。 |
| 目录 / 章节 | 目录像赛事阶段条目，章节采用一个大编号与斜向边缘色带。 |
| 正文 / 图文 | 正文用白底或极浅灰版，蓝色标题；场地绿只用小范围，不把全篇铺成草坪。 |
| 对比 / 表格 | 对比用对齐的条件或方案两列；表格深蓝表头、白底数据，比分式大数字仅用于资料真实数字。 |
| 流程 / 数据图 | 流程可采用横向推进的赛事节奏，信息箭头原生；图表蓝/紫为主，绿只表示明确类别。 |
| 结尾 | 结尾用干净蓝色与小型台座，减少奖杯堆叠。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：蓝紫赛事海报空间、斜向白边与稀疏网纹，右侧资料概念成为台座上的主物件；正文区域低纹理。
- 透明装饰：金属台座、蓝白速度翼、与资料概念结合的奖杯式抽象物件，单件透明底。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。

不把虚构比分、排名、百分比当装饰，也不复制促融共竞的白底彩环作为整套识别。
