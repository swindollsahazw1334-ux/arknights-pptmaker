## 视觉识别

**白色竞技空间与红青绿环带**。白色三维场馆、黑色分段圆台与红/青/荧光绿环带；不同项目使用不同主色，回合页以大留白和青色条组织信息。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 底色 | `#F1F2EF` |
| 正文 | `#252729` |
| 次字 | `#656C6E` |
| 红色 | `#D82050` |
| 青色 | `#31AFC0` |
| 荧光绿 | `#BCE83B` |
| 浅面 | `#DDE2DF` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：微软雅黑中文，Bahnschrift 英文与数字；短标题可用粗体，正文保持常规粗细。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 白灰底配右侧立体台座，彩色环带沿边缘运动；主文区黑字。 |
| 目录 / 章节 | 目录用项目名称与单个编号，章节让红/青/绿轮换为主强调色。 |
| 正文 / 图文 | 正文仍使用白色平面，图片与字幕独立；避免把队伍空位按钮搬到教学内容中。 |
| 对比 / 表格 | 协作/方案对比使用同一栏宽；表格浅灰底、深色字，红青只分组。 |
| 流程 / 数据图 | 流程节点和连线原生，颜色对应真实角色；图表不使用游戏的胜率或虚构积分填满页面。 |
| 结尾 | 结尾保留一段环带和小型场馆构件，减少多色竞争。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：白灰体育节展台、黑色分段底座与红青绿细环带；让资料概念成为展台上的主物件，环带绕开文字。
- 透明装饰：白色折面台座加黑色分段环与红/青/绿一至两条细带，单件真实透明底。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。
