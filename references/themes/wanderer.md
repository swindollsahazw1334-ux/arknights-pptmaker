## 视觉识别

**麦田、厚云与黄昏印刷品**。成熟麦色、沉重灰云与锈红标题，乡野远景和大幅留白传达沉静；纸面、衬线层级和温暖侧光适合讲述选择与取舍。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 浅纸 | `#E8D4AC` |
| 正文 | `#363B3A` |
| 次字 | `#70684F` |
| 麦金 | `#B69B62` |
| 锈红 | `#B34C2D` |
| 深云 | `#444C4D` |
| 高光 | `#F4E7C6` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：宋体或微软雅黑标题，正文微软雅黑；Georgia 英文短标题有报刊气质，避免所有文字使用细衬线。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 左侧浅纸标题、右侧黄昏景观或资料相关主物件；云层避开正文。 |
| 目录 / 章节 | 目录用简洁纵向栏目，章节使用麦金/深云的明暗切换。 |
| 正文 / 图文 | 正文以浅纸阅读面为主，图文用边界明确的横向图窗；长段不压在麦田上。 |
| 对比 / 表格 | 对比采用两栏相同项目，表格锈红小表头或深云表头、浅金横线。 |
| 流程 / 数据图 | 流程用深云线和锈红重点，图表只保留必要刻度；金色作为强调不能降低数值对比。 |
| 结尾 | 结尾留远景与短结论，不添加无依据的抒情引用。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：黄昏麦田、厚云与温暖浅纸，资料主题转译为乡野观察或独立物件；主体在右，阅读区纸纹轻。
- 透明装饰：麦穗、铜色测绘板、锈红布条组成一件不带字的透明静物；不用骑士徽章代替全部装饰。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。

不是热带假日或古风卷轴。图库同页的联动宣传、家具和时装需要逐张确认归属。
