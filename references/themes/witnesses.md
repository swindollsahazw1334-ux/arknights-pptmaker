## 视觉识别

**冷白建筑图纸与蓝色精细构造**。冷白与浅青蓝占大面积，细蓝构造线、竖向建筑与同心圆形成精密感；轮廓、轨迹与地图叠层比厚重金色圣堂更接近正文 UI。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 纸底 | `#F4F7F6` |
| 浅蓝 | `#DDECF0` |
| 正文 | `#254853` |
| 次字 | `#68818B` |
| 蓝色 | `#327EC0` |
| 金色 | `#B6A478` |
| 深蓝 | `#233E52` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：微软雅黑中文，Georgia 英文衬线用于少量标题，Consolas 用于真实编号与工坊信息。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 冷白大留白配右侧纵向建筑或资料概念插画，标题深青；蓝线只做轻引导。 |
| 目录 / 章节 | 目录用细蓝轴和真实章节序号，章节保持单个高挑竖向构件。 |
| 正文 / 图文 | 正文白底细网格，图像像图纸插页；字块边缘与建筑线错开。 |
| 对比 / 表格 | 对比使用一致的细线栏，表格深青表头、浅蓝分隔；少量金色表示重点，不铺金边。 |
| 流程 / 数据图 | 流程用蓝色原生连线与空心节点；图表坐标、数值和单位清晰，概念构造线不能冒充数据。 |
| 结尾 | 结尾回到冷白空场，小型蓝色构件收束。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：冷白现代建筑图纸、浅青透叠与细蓝构造线，资料主题转译为精密展件；大段文字所在区域保持空白。
- 透明装饰：白色晶体拱形、细蓝环线与高挑构件的单件透明组合，避免任何既有宗教或活动徽标的精确复制。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。

不统一成金色宗教纹样或深色科技 HUD；周年其他节目中的鲜黄/橙红视觉不混入本活动。
