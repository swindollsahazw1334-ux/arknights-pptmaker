## 视觉识别

**黑钢工业、酸黄警戒与城市纪实**。酸黄与黑灰、橄榄色形成强烈安全标识感，斜向警戒带、钢材、城市围墙和粗颗粒印刷强化工业与安保气质。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 深底 | `#202624` |
| 浅底 | `#EBEADB` |
| 正文 | `#F1F0D9` |
| 次字 | `#B7BBA8` |
| 酸黄 | `#E1E83B` |
| 橄榄 | `#747D43` |
| 墨黑 | `#171D1B` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：微软雅黑粗体标题，Bahnschrift 英文，Consolas 短编号；正文保持足够粗细。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 黑色主场、酸黄短强调，右侧城市或资料概念插画；不必用牛仔题材表达活动身份。 |
| 目录 / 章节 | 目录用工业清单条目，章节以一段警戒带和大编号换气。 |
| 正文 / 图文 | 正文优先浅灰或米白版本，深底只用于章节或短段；黄色不能当小字号长文。 |
| 对比 / 表格 | 对比采用统一字段，黑灰区分层级、酸黄指出差异；表格浅底深字，证据照片保留原色。 |
| 流程 / 数据图 | 风险流程用原生连线和明确标签，警戒条只在外缘；图表不使用虚构安防读数。 |
| 结尾 | 结尾用少量钢材和一段酸黄边签，留下明确结论。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：粗颗粒黑钢与灰色水泥、少量酸黄警戒条；资料主题放入工业城市语境，大块低纹理文字区。
- 透明装饰：钢材角件、警戒带或小型混凝土碎片构成一件透明饰物；预留原生标签位置。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。

不是棕色西部通缉令模板，也不能把黄色渲染气氛当作真实危险等级。
