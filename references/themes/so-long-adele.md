## 视觉识别

**粉色云海、暖纸与轻快旅行印刷品**。粉色云海、暖光、植物与轻盈旅行物料，奶油、珊瑚、湖绿和靛紫夜色可按章节变化；纸片、票签与图框有错位但阅读面清楚。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 纸底 | `#F4E5C8` |
| 正文 | `#254A43` |
| 次字 | `#617269` |
| 珊瑚红 | `#D95663` |
| 湖绿 | `#279C97` |
| 粉云 | `#E9B8CB` |
| 夜色 | `#3E426E` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：微软雅黑中文，Bahnschrift 英文短标题；装饰用旅行印刷纹理，不用手写字承载长段。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 奶油阅读区配粉云或暖光主景，资料主体在独立图片里表现。 |
| 目录 / 章节 | 目录用旅行印刷品条目，章节轮换薄荷绿、粉云或夜色，保留统一字号。 |
| 正文 / 图文 | 正文浅纸深绿字，照片与说明分层，票签和相框可独立移动。 |
| 对比 / 表格 | 对比使用同一栏目，表格深绿表头、浅奶油格，珊瑚红强调少量差异。 |
| 流程 / 数据图 | 流程原生连线，图表湖绿/珊瑚为主；为读数去掉绘图区纹理，不添加无依据的旅游数据。 |
| 结尾 | 结尾采用安静晚霞或夜色，适当减少装饰。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：粉云、海滨暖光与植物边缘，加入与资料相关的城市/物件，正文在奶油纸面上；章节生成薄荷或夜色变化。
- 透明装饰：旅行票签、错位纸片、云朵植物或相框单件透明装饰；保持空白标签。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。

不把整套限制为红色格纹奶油底，不做孤星档案模板换色。
