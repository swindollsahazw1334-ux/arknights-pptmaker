## 视觉识别

**都市海滨、钴蓝涂绘与彩色贴纸**。折皱白纸与饱和蓝色涂绘，湖蓝海水、黄色贴纸、粉绿小标签形成快节奏；与柔软粉云夏日相比更接近城市运动刊物。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 纸底 | `#F4F3ED` |
| 正文 | `#202632` |
| 钴蓝 | `#0649ED` |
| 湖蓝 | `#2CBBD0` |
| 亮黄 | `#F6D925` |
| 粉色 | `#E35A91` |
| 绿色 | `#349861` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：微软雅黑中文，Bahnschrift 粗体英文和大数字；涂绘感放在生成图案，不把正文做成潦草字。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 折纸白底与右侧海滨/资料概念拼贴，钴蓝标题和少量亮黄边角。 |
| 目录 / 章节 | 目录用活动手册式大编号，章节切换白纸/深蓝，涂绘集中边缘。 |
| 正文 / 图文 | 正文白纸深字，照片、贴纸和图注独立，保留资料实拍颜色。 |
| 对比 / 表格 | 对比用相同栏目，表格深蓝表头、浅灰横线；亮黄小标签不要替代数值标题。 |
| 流程 / 数据图 | 流程使用清楚原生箭头和文字，波浪装饰避开节点；图表钴蓝/湖蓝为主，粉或黄只在需要时区分类别。 |
| 结尾 | 结尾用干净蓝色或少量海浪纸饰，不堆多个旅游贴纸。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：折皱白纸、钴蓝笔触、湖蓝海水与亮黄斜角；根据资料选择城市、物件或场景，贴纸和大字分层。
- 透明装饰：海浪与浮标、折纸角或运动贴纸式单件透明拼贴，蓝黄为主、粉绿少量。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。

不与火山旅梦的珊瑚粉云海混用，也不按海滨名义给学术资料添加无关海滩人物。
