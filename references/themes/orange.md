## 视觉识别

**蓝天、公路旅行与手作笔记**。天空蓝与纸白构成主场，旅行小屋、汽车、公路和手账拼贴承担叙事；星芒、路线细线、打孔纸和黄色小花提供轻盈细节。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 纸底 | `#FFF8E8` |
| 正文 | `#234A63` |
| 次字 | `#617D88` |
| 天蓝 | `#6ABFDD` |
| 群青 | `#246BA1` |
| 奶油黄 | `#F3CE65` |
| 杏橙 | `#DF9855` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：微软雅黑标题与正文，少量 Georgia 英文衬线作旅行印刷品层级；手写感交给图案，正文保持印刷体。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 纸页占左侧或中部，右侧采用与资料相符的旅行式场景；不要按中文名称铺满酸绿色。 |
| 目录 / 章节 | 目录用行程条目与小编号，章节更换纸页裁口和蓝色浓淡，避免每页同一张手账。 |
| 正文 / 图文 | 正文在浅纸上横排，照片与便签独立放置，纸边不侵入数据和说明。 |
| 对比 / 表格 | 对比用两页笔记的相同栏目；表格用淡蓝横线、深蓝表头和完整单位。 |
| 流程 / 数据图 | 流程可借用路线布局但箭头须可编辑；图表用蓝色与杏橙区分类别，纸纹在绘图区减弱。 |
| 结尾 | 结尾用安静的天空或合上的旅行笔记，小星芒留在外缘。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：蓝白旅行手账，资料主题成为沿途观察到的场景或物件；天空、纸页、稀疏星芒和细路线只在边缘，保留大面积浅纸供原生文字排版。
- 透明装饰：空白打孔纸、蓝黄丝带、车票状空白纸饰或围绕资料物件的旅行贴纸；标题和手写标注不烘焙。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。

不是柑橘广告，也不等于火山旅梦的粉色云海。原活动英文标题含 Orange，用户中文仍按“直到大地变成一颗酸橙”匹配，不自行改名。
