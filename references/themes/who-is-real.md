## 视觉识别

**纸白、矿物墨绿与朱砂**。稀疏墨绿山水、纸面透叠和朱砂印记，疏密对照与大留白构成识别；印刷字段保持现代信息感。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 纸底 | `#F2F1E8` |
| 正文 | `#283E37` |
| 次字 | `#697A6F` |
| 灰绿 | `#849C8B` |
| 朱砂 | `#B64739` |
| 浅墨 | `#C9D2C4` |
| 白色 | `#FAFAF2` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：宋体短标题，正文微软雅黑保证清晰；英文 Georgia 或 Consolas 仅作少量辅助，不用伪书法当正文。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 大留白、墨绿标题与右侧稀疏山水/资料概念，朱砂只一处。 |
| 目录 / 章节 | 目录用轻纵向次序，章节可放一组竖排短字；正文仍水平排版。 |
| 正文 / 图文 | 纸白读区与独立图窗，墨痕在外缘；原图中的证据和数字保持原色原意。 |
| 对比 / 表格 | 比较对象同一层级，表格墨色表头、淡灰绿分隔，朱砂用于少量重点。 |
| 流程 / 数据图 | 流程连线与文字原生，墨画不能代替信息节点；数据轴线深墨、数值完整，不用笔触装成量化曲线。 |
| 结尾 | 结尾以空纸、短标题与单件松石装饰收束。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：矿物墨绿山水、浅灰绿雾与细朱砂，资料主题可作现代墨绘概念；留白区域只保留轻纸纹，不生成书法标题。
- 透明装饰：松石、山峦或干笔墨痕的一件透明拼贴；印记为空白造型，所有可读文字另排。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。

不是满页古风卷轴，朱砂印章不要烘焙正文、姓名或伪造落款。
