## 视觉识别

**白色展陈、三维构件与荧光点色**。白灰空间中以黑色桁架定结构，青色、荧光黄、洋红区分展区；浮雕图形、对话形标签和等距展台形成轻巧展会感。

| 色彩角色 | PPT 建议值 |
| --- | --- |
| 底色 | `#F1F2EF` |
| 正文 | `#171A1B` |
| 次字 | `#62696B` |
| 青色 | `#16C9D1` |
| 荧光黄 | `#E4FA4E` |
| 洋红 | `#E34E99` |
| 浅面 | `#E0E4E3` |

以上是 PPT 设计值，不是官方色板。颜色用于区分层级，正文优先深浅对比；细字不直接采用浅亮装饰色。字体为易用替代字体：微软雅黑标题与正文，Bahnschrift 英文，Consolas 小编号。

## 页面转译

以 1280×720 为参考，标题约 42–64 px，正文约 24–30 px；先删减重复叙述，再调整字号。实际版面服从资料和预览。

| 页面目的 | 版式建议 |
| --- | --- |
| 封面 | 左侧清楚的大标题，右侧一组展陈式资料概念插画；保持白色主场。 |
| 目录 / 章节 | 目录用展区编号和一条导览次序，章节用单个展位编号；编号与标题均为原生文字。 |
| 正文 / 图文 | 白底深色正文，图像像展品一样独立陈列；彩色边签只强调当前信息。 |
| 对比 / 表格 | 对比内容横向并置，青/洋红作条件区分；表格浅灰线、黑表头，避免给每格做按钮。 |
| 流程 / 数据图 | 流程像导览路线，连接关系用原生箭头；图表用黑色基线和少量青/洋红数据。 |
| 结尾 | 结尾保留一组小型展陈构件和短标题；不堆展位按钮。 |

## 生图与混合分层

按 [生图与素材分层](../imagegen.md) 执行：资料决定主体，活动参考决定造型、材质、颜色与留白。以下是提示词的视觉约束，必须加入本页真实的概念/场景和文字安全区后实际调用 imagegen。

- 背景：白灰展厅、黑色细桁架与等距白色台座放在边缘或右侧，青/黄/洋红形成有限的色块；资料主体可转译为台座上的展品，正文区保持干净。
- 透明装饰：单件三维展台、浮雕环形构件或桁架角件，青/黄/洋红只选两种为主色，真实透明底。
- 内容插画：根据本页资料选择场景或物件，沿用上述媒介和颜色；概念插画不充当原始证据或量化图。
- 所有标题、正文、页码和可读标签使用原生文字。数据表、数据图和有语义的关系线保持可编辑。生成图不含这些文字与数字；背景和需要移动的装饰分别生成、分别放置，检查实际 alpha。
- 章节至少按内容改变构图、明暗或主强调色。样张不是固定背景，不能将其整页贴入正式 PPT 后声称可编辑。

不要把展会对话标签当作实际软件按钮，不使用孤星的暖纸橙色档案底，也不把全页做成彩色积木。
