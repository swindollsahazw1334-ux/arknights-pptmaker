# 按资料内容与活动主题生图

此流程是默认制作步骤：实际调用内置 imagegen，检查并使用生成素材。不要只交付提示词或用程序绘制的装饰冒充生图。用户已选定主题并授权制作时直接执行，不增加生图审批轮次。

## 从资料到画面

先理解资料，再安排素材。内容依据和风格依据分开记录：

| 输入 | 决定什么 |
| --- | --- |
| 上传文档、图片、用户回答 | 主题、章节含义、需要解释的概念、应保留的照片和数据 |
| 所选活动的主视觉、UI、装饰参考 | 色彩角色、明暗层次、构图、质感、图案和装饰语言 |
| 逐页内容计划与图文偏好 | 素材用途、画面比例、重心、正文与照片的留白区域 |

不要仅凭活动名字编造视觉规则。先看 [主题配方](themes.md) 对应参考；尚无配方时按其中的研究流程获取依据。有合适参考图时按工具支持的方式作为风格参考附入，并说明它的用途；上传的内容图片与活动风格图不能混为同一种输入。

在工作目录保存素材计划，可使用 `visual-assets/asset-map.json`。每项记录 `id`、`role`（background/decoration/illustration）、`slideIds`、`sourceIds` 或内容摘要、`styleReferences`、比例、留白要求和是否透明。按页面需要创作可复用的背景系列与装饰，不要求每页重新生一套，也不把同一背景铺满全稿。

例如“澳门学生省钱生活”的餐饮、购物、交通、娱乐资料搭配“火山旅梦”：以旅行印刷品、粉色云海和清新的色彩组织各章，分别创作餐饮纸饰、购物票签、交通路线意象和夜间娱乐氛围。地点实拍、商家照片和票价仍采用资料原件与可编辑文字；主题里的火山或幻想云景属于装饰，不能标作澳门实景。此例的题材与夏日元素不适用于所有资料或活动。

## 素材拆分与提示词

| 素材 | 生成与分层要求 |
| --- | --- |
| 背景 | 通常按 16:9 设计；保留真实可用的文字和照片安全区，视觉重心避开正文；不承载正文或数据 |
| 装饰 | 按独立移动的单位生成，如花簇、纸饰、相框、印记；使用真实透明背景，四周留出完整边缘 |
| 补充插画 | 画资料涉及的概念或情境，风格遵循所选活动；与背景和文字分别放置 |

提示词写清楚可观察的视觉特征，而非只有“明日方舟风格”。按需采用下列结构：

```text
用途：PPT 的 [背景 / 独立透明装饰 / 插画]，画面比例与放置位置为……
内容依据：上传资料的……章节讲述……；画面需要表达……
活动风格：参考已查看的……活动；采用……配色、构图、纹理和装饰语言。
主体与细节：……；原资料中的照片、数据和文字由 PPT 另行承载。
构图与留白：主体位于……；为……位置的标题、正文或照片保留干净区域。
色彩关系：本页主色……、辅助色……、强调色……，与整套素材保持一致并有变化。
输出约束：无文字、字母、数字、页码、水印或商标；装饰部件完整；[透明 / 不透明] 背景。
```

只加入与资料和主题相关的画面内容。不要为了套活动风格自动加入无关角色、剧情或装置；不要让模型绘制事实表格、带数值的图表或需要编辑的文字。

## 实际调用与检查

- 使用当前会话内置 `image_gen` 工具（如 `image_gen.imagegen`）；无需用户配置独立 API 或密钥。多项不同素材分别调用，提示词写明各自用途。
- 透明装饰设置 `transparent_background: true`，不透明背景设置为 `false`。参考图的传入方式遵循当前工具说明；本地参考或待编辑图片先查看，再正确标注参考图和编辑目标。
- 生成后查看图片，检查主题风格、内容关联、留白、裁边和意外文字；检查透明 PNG 的实际 alpha，避免白底或棋盘格被画进文件。必要时针对具体问题调用 imagegen 修改或重生成。
- 把选用原图复制到本次工作目录，不能只引用 Codex 默认生成目录。保存完整提示词、工具方式、参考来源与最终文件的对应关系；后续修改保留原图和新版本。
- 工具不可用或失败时如实说明。不能悄悄用几何占位图冒充完成，也不能自行切换需要密钥的 CLI/API；仅在用户明确选择该路径后采用。

## 嵌入与验收

背景置于底层；装饰、资料照片、说明、正文和数据分别成层。相框与照片独立；需要移动的装饰放成单独图片对象。全稿文字仍用原生文本，图表按资料数据制作，不能把完整幻灯片生成为一张图。

可保留高分辨率原图，同时为嵌入制作适当尺寸的副本；转换与压缩保留透明通道，不改变内容。重复使用的素材可复用媒体资源，各次放置仍需能独立移动。遇到体积或导出限制时优化素材尺寸和资源重复，不通过放宽检查掩盖问题。

渲染后同时看整套缩略图和单页：活动特征是否明确，颜色和版式是否有节奏，图像是否贴合内容，文字安全区是否实际可用，装饰是否遮挡内容。提示词要求留白不代表输出一定满足，按实际图像调整版式或重新生成。保留生成原图和提示词供复用；交付时简短说明已使用内置 imagegen，以及文字与图片层的编辑范围。
